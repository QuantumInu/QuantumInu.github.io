# Quantum Inu ($QI) — Main Site

Main website for Quantum Inu ($QI) on Solana, with a built-in PFP generator.

## Files for GitHub Pages

Upload these to the root of the repo (not inside a subfolder):

```
index.html
assets/
  qi-logo.png
```

Then in the repo: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## What's inside

- Hero with official contract + copy button
- About and How to Buy
- PFP Generator: upload a photo or use the QI dog, choose background / layout / overlay / filter / badge, download a 1024×1024 PNG. Runs fully in the browser.
- Gallery and community links (X @QuantumInu4L, Telegram @QuantumInuOfficial)
